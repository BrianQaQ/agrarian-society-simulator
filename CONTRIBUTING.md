# Contributing

Contributions that improve mechanism transparency, calibration, tests or
visualization are welcome.

1. Fork the repository and create a focused branch.
2. Keep the core model free of unexplained buffs and scripted outcomes.
3. Add or update tests for every behavioral change.
4. Run `python3 -m unittest -v` before opening a pull request.
5. Explain the causal assumption and expected aggregate effect in the PR.

Historical calibration data should include its source, units, geography and
time period. Avoid presenting an uncalibrated parameter as a historical fact.
