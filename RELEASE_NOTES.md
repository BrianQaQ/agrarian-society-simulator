# v1.0.0 — Initial public release

The first stable release of the bottom-up agrarian society simulator.

## Highlights

- Observe rather than govern: there is no ruler gameplay or event buff system.
- Compare fixed institutional rules with strategies selected through descendant survival.
- Track binary equal-division versus primogeniture choices by population share.
- Watch land concentration create persistent material pressure and endogenous uprisings.
- Inspect separate demographic, land, conflict and strategy charts.
- Export complete yearly histories for external analysis.

The model is an explicit counterfactual laboratory, not a calibrated prediction
of any particular historical dynasty.
