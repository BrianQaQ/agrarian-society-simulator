# 土地、家族与周期：底层农业社会模拟

[![Tests](https://github.com/BrianQaQ/agrarian-society-simulator/actions/workflows/tests.yml/badge.svg)](https://github.com/BrianQaQ/agrarian-society-simulator/actions/workflows/tests.yml)
[![Release](https://img.shields.io/github/v/release/BrianQaQ/agrarian-society-simulator)](https://github.com/BrianQaQ/agrarian-society-simulator/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

这是一个观察者视角的代理模型，目标是从家户层面的生存约束推出古代王朝的历史周期律、财富分配不均和马太效应。它不模拟皇帝，不提供赈灾、军事、科技等经营按钮，也没有剧本事件或隐藏 Buff。唯一的随机性是年景：收成每年都有丰歉，这是前现代农业的物理事实。

## 机制

1. **生产与租佃**：土地和劳动按 Cobb-Douglas 函数产粮，边际产出递减。租佃市场是竞争性的：每人得到劳动的边际产出，每亩得到土地的边际产出。因此地租份额等于土地产出弹性（默认 0.5，即主佃对分），而每亩地租随人口增加而上升。
2. **年景**：每年收成乘以一个随机系数，一半是全区共同的丰歉，一半是各家各户的运气。
3. **口粮与人口**：每人每年必须消耗最低口粮，短缺会提高死亡率、压低生育率。家户人数是整数，生死按概率抽取。
4. **借贷与失地**：缺粮的家户以土地作抵押，向有余粮的家户借粮，年息默认 40%。秋后先还债，利息照算；债务一旦超过土地价值，土地就归债主。富户放贷、穷户失地，这是马太效应的主要渠道。
5. **地价**：地价等于扣除田赋后的每亩净地租乘以“年租倍数”（默认 12 年）。田赋越重，地价越低。
6. **国家财政与隐田**：国家每年需要一笔固定数额，开国时为总产出的 8%，此后每年增长 0.7%（冗官、冗兵、宗室）。田赋只摊在登记在册的土地上。占地越多的家户越能把地隐出册籍（优免、诡寄）：占地是平均的 10 倍时，最终可隐去全部土地。隐田越多，在册小户的负担越重（黄宗羲定律）。每亩田赋最多等于每亩地租，再收不上来就是财政缺口。
7. **继承**：每户每 25 年分家一次，继承人数按家庭人口随机抽取（户均五口）。吃得饱的家庭儿子多，均分时家产分得更碎；长子继承则让次子们成为无地支系。
8. **起义**：家户记得近年的饥饿。饥饿记忆超过自身反抗阈值的人口构成动员人口。动员比例超过“国家可镇压比例 × 财政充足率”时，爆发大起义。财政越空虚，越小的动乱就能推翻王朝。
9. **战乱与新朝**：战乱期间不收税、不收租、不讨债。土地的那一份产出被军队征发和破坏吞掉，人人只靠劳动收入过活，起义者还有额外的战死风险。等幸存者靠劳动收入（连同无主荒地）能重新吃饱、动员也平息下来，新王朝建立：重新清丈土地（隐田清零），旧债作废，无主荒地按人口分给幸存者，起义者分得双份，财政需求按新的产出重新起算。

土地在生产、借贷、继承、战乱和建国中严格守恒。

## 两种模式

### 固定规则

所有家户使用同一套生育、存粮、放贷和继承策略，适合做控制变量实验，例如：

- 均分继承与长子继承的长期差异；
- 借贷利率、财政增长、隐田速度如何改变王朝寿命和土地集中；
- 年景波动对兼并速度的影响。

### 策略演化

初始家庭拥有随机策略。每次分家时，后代复制父代策略并有小概率变异。模型不替代理人做全知最优化；策略的“最优”由达尔文选择定义：一种策略如果能留下更多存活后代，它在总人口中的占比就会上升。

可演化的基因包括：生育率、目标存粮年数、余粮放贷比例、加入起义的饥饿阈值，以及均分继承或长子继承。

## 参数

| 参数 | 默认值 | 单位 | 依据 |
|---|---|---|---|
| 亩产 `yield_per_mu` | 2.0 | 石/亩 | 明清常见亩产量级，在人均 4 亩时取得 |
| 参考人均耕地 `reference_land` | 4.0 | 亩/人 | 洪亮吉《治平篇》“一岁一人之食约得四亩” |
| 土地产出弹性 `land_elasticity` | 0.5 | — | 等于竞争性地租份额，对应主佃对分 |
| 人均生存消耗 `subsistence` | 4.0 | 石/人/年 | 口粮加最低限度的衣、柴等折粮 |
| 基础死亡率 `baseline_mortality` | 3% | /年 | 前现代粗死亡率约 30‰ |
| 饥饿死亡率 `shortage_mortality` | 0.30 | — | 每缺一成口粮，死亡率上升 3 个百分点 |
| 生育率（策略） `fertility` | 4% | /年 | 前现代粗出生率约 35–45‰ |
| 年景变异系数 `harvest_cv` | 0.20 | — | 前现代单产年际波动的常见量级 |
| 借贷年利率 `interest_rate` | 40% | /年 | 《大明律》私债月息不得过三分（年约 36%），民间粮债常更高 |
| 年租倍数 `years_purchase` | 12 | 年 | 明清地价常为年租的十余倍 |
| 开国财政需求 `fiscal_burden` | 8% | 产出 | 田赋正额加徭役折算的量级 |
| 财政需求年增长 `fiscal_growth` | 0.7% | /年 | **按王朝寿命校准**，见下文 |
| 隐田速度 `evasion_rate` | 1% | /年 | 明中后期在册田亩大幅缩减；缺少直接测量 |
| 国家可镇压的动员比例 `revolt_threshold` | 20% | 人口 | 缺少直接测量 |
| 起义者战死率 `war_mortality` | 3% | /年 | 非起义者减半 |

## 运行

要求 Python 3.10+ 和 Tkinter，不需要第三方包。

```bash
python3 main.py
```

macOS 也可以双击 `run.command`。

命令行批量实验：

```bash
python3 main.py --years 800 --mode fixed --inheritance equal
python3 main.py --years 800 --fiscal-growth 0.005 --interest 0.3 --csv history.csv
python3 main.py --years 800 --mode evolution --mutation 0.06 --csv evolution.csv
```

运行测试：

```bash
python3 -m unittest -v
```

测试覆盖土地守恒、债务与债权相等、抵债失地、隐田转嫁税负、强制起义后新朝重置、分家人口守恒、固定策略不漂移、演化可复现、均分继承下的兼并与改朝，以及数值稳定和 CSV 导出。

## 结果与检验

种子 1–6，各跑 1000 年，统计每次王朝崩溃时的状态（中位数）：

| 设置 | 王朝寿命 | 战乱年数 | 战乱中人口损失 | 崩溃时土地基尼 | 崩溃时无地人口 |
|---|---|---|---|---|---|
| 默认（均分继承） | 220 年（168–302） | 9 | 23% | 0.65 | 28% |
| 策略演化 | 203 年（43–360） | 10 | 20% | 0.85 | 53% |
| 长子继承 | 130 年（26–319） | 3 | 12% | 0.82 | 64% |
| 无隐田（`evasion_rate=0`） | 271 年（222–346） | 4 | 19% | 0.71 | 41% |
| 无年景波动（`harvest_cv=0`） | 1000 年内无改朝 | — | — | — | — |

对照历史：

- **均分继承下照样兼并**：中国自秦汉以来基本实行诸子均分，土地兼并和王朝周期仍反复出现。模型中，即使在均分继承下，基尼系数也会从开国时的 0.2–0.3 升到 0.6 以上。
- **王朝寿命**：主要统一王朝约 170–290 年（北宋 167、唐 289、明 276、清 268）。`fiscal_growth` 缺少直接测量，是按这一点校准的，所以王朝寿命不算独立检验。
- **土地分配**：民国土地调查中，土地基尼大致在 0.5–0.7，具体数字有争议；佃农和无地者约占三到五成。
- **年景是兼并的发动机**：没有丰歉时，几乎没有人需要借贷，马太效应和周期都不会出现。

已知不足：

- 战乱比历史上短，人口损失也偏小。历史上的改朝换代多持续 13–35 年，人口损失两到四成（估计有争议）。
- 只有一个区域：没有南北差异、人口迁移和边疆。
- 国家不做决策：没有变法、赈灾或外敌入侵。

## 如何理解结果

本项目追求的是“机制透明”，而不是宣称还原全部古代历史。参数决定的是一个明确的反事实世界。历史写实度应通过真实的人口、亩产、口粮、租率、利率、税负和继承数据逐步校准，而不应靠加入更多不可检验的事件修正项。
